# I. Présentation de la structure

## 1.1 Activités

La CCABSV est un Établissement Public de Coopération Intercommunale (EPCI) créé en 2002 et recomposé en 2017.

### Communes membres
- La Capelle-Bleys
- La Salvetat-Peyralès
- Le Bas-Ségala
- Lescure-Jaoul
- Prévinquières
- Rieupeyroux
- Tayrac

**Population au 01/01/2026 : 5 735 habitants**

# II. Présentation du projet de site internet

## 2.1 Objectifs

Le nouveau site doit :

- Améliorer la visibilité de la communauté
- Faciliter l'accès à l'information
- Valoriser le territoire
- Promouvoir les actions communautaires
- Centraliser les informations des services
- Proposer un agenda communautaire

## 2.2 Publics cibles

- Habitants du territoire
- Nouveaux habitants
- Entrepreneurs
- Presse

- Un élu référent

# III. Exigences techniques

## 3.1 Fonctionnalités

### Contenus

- Vidéos
- Sons
- PDF téléchargeables
- Consultation type Calaméo

### Accessibilité

Conformité :

- RGAA niveau AA

### Fonctionnalités

- Responsive mobile
- Moteur de recherche performant
- Widgets ADAT / SITA
- Compatibilité navigateurs récents
- Pop-up d'information
- Statistiques via GA4
- Formulaires de contact
- Réseaux sociaux
- Accès contributeurs
- Espace intranet

## 3.2 Graphisme et ergonomie

### Sites de référence

- https://www.cc-millaugrandscausses.fr/
- https://www.cc-paysdesachards.fr/
- https://www.provenceverdon.fr/

### Exigences

- Respect de la charte graphique
- Page d’accueil moderne
- Agenda intégré
- Actualités visibles
- Règle des 3 clics
- Menu Burger
- Carte interactive du territoire

### Carte interactive

Données provenant du :

**SITA (Système d'Informations Touristiques de l'Aveyron)**

Formats attendus :

- JSON
- Flux de données externes

### RGPD

- Mentions légales
- Politique de confidentialité
- CGU
- Gestionnaire de consentement CNIL

### Sécurité

- HTTPS obligatoire
- SSL
- reCAPTCHA v3
- Sauvegardes régulières
- PRA (Plan de Reprise d’Activité)

### Maintenance

- Corrective
- Préventive
- Évolutive

### Garantie

Période souhaitée :

- 3 à 6 mois après livraison
