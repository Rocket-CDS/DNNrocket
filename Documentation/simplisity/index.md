# Simplisity.js

Simplisity is a client-side jQuery-based framework combined with a set of server-side utilities. The goal is to keep things as simple and flexible as possible.

Simplisity is designed to take data from the HTML page, pass it to a server-side API for processing, and then return data or HTML to be added back to the page.
